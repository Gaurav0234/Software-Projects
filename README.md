## Projects

### 1. Rappi Turbo — AI Purchasing Agent

**Tech:** Python, FastAPI, SQLite, OpenAI Responses API, JavaScript, HTML/CSS, Docker

An AI-powered purchasing agent built as an engineering assignment.

The system investigates a purchasing situation using tools, evaluates inventory, forecasts, purchase orders, supplier conditions and business constraints, proposes a purchasing decision, validates that decision using deterministic guardrails, and requires human approval before execution.

The system also verifies the outcome after creating a purchase order and escalates when the persisted result differs from the approved intent.

#### Key concepts demonstrated

- LLM tool calling
- Multi-step agent workflow
- Tool-based investigation
- Deterministic business-rule guardrails
- Human-in-the-loop approval
- Purchase order execution
- Post-action validation
- Failure detection and escalation
- Audit trail
- LLM fallback handling
- Automated tests

[View Project →](./Rappi-AI-Purchasing-Agent/)
